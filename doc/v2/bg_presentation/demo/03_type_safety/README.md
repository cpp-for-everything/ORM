# Демо 3 — Типова съвместимост поле↔стойност (при компилация)

**Какво доказва (оси):** (а) `constexpr` IR + (г) валидиране при компилация. Сравнение
на колона със стойност от несъвместим тип е отказ на компилатора. *(Проверката е
добавена след предаването на тезата — продължаващо развитие.)*

## Файлове
- `type_safety.cpp` — валидни сравнения + (под `-DDEMO_REJECT`) едно несъвместимо.
- `program-output.txt` — валидните сравнения се компилират и изпълняват.
- `compiler-output.txt` — уловеният отказ за `int` колона срещу низов тип.

## Команди
```
c++ -std=c++23 -I lib/include type_safety.cpp                # компилира
c++ -std=c++23 -I lib/include -DDEMO_REJECT type_safety.cpp  # static_assert
```

## Какво да кажете (≈15 s)
> Операторите изваждат C++ типа на колоната и на стойността и ги сверяват.
> `score > 0` минава (double срещу int е конвертируемо), но `id == "текст"` е отказ на
> компилатора: `incompatible operand types in a field comparison`.
