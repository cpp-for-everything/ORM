# Демо 2 — Заявката е типизирана стойност, а не низ

**Какво доказва (ос):** (а) `constexpr` междинно представяне на заявката. Заявката
се изгражда от composable части и всеки инвариант е проверен със `static_assert` —
компилаторът проверява структурата ѝ, без да изпълни и ред код.

## Файлове
- `query_anatomy.cpp` — изгражда SELECT/WHERE/ORDER BY/LIMIT като типизирана стойност.
- `program-output.txt` — изходът (компилира се и потвърждава, че всичко е проверено).

## Команда
```
c++ -std=c++23 -I lib/include query_anatomy.cpp -o anatomy && ./anatomy
```

## Какво да кажете (≈15 s)
> Заявката тук не е низ — тя е `constexpr` стойност. Имената на колоните, броят на
> клаузите, видът на всеки операнд са в типа и са проверени със `static_assert`. SOCI
> изгражда низ при изпълнение; sqlpp11 е типизиран, но само за SQL — тук същият модел
> е основата за релационни и нерелационни системи.
