template<typename IntoTable, is_type_container InsertedColumns, typename SelectQuery, is_type_container OnDuplicateKeyUpdateAssignments>
class webframe::ORM::details::InsertIntoSelectQuery< IntoTable, InsertedColumns, SelectQuery, OnDuplicateKeyUpdateAssignments >

Insert into select query class.

Template Parameters
IntoTableThe class representing the table or collection where the data is going to get inserted
InsertedColumnsSet of mem_ptr_wrappers containing the columns which would be given values. All columns should be from the same class.
SelectQueryThe type of the select query that would be used in the insert into select query
OnDuplicateKeyUpdateAssignmentsSet of assigments which would be executed on duplicated data being inserted
