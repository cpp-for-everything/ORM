Detailed Description

template<typename IntoTable, is_type_container InsertedColumns, is_type_container InsertedValues, is_type_container OnDuplicateKeyUpdateAssignments>
class webframe::ORM::details::InsertQuery< IntoTable, InsertedColumns, InsertedValues, OnDuplicateKeyUpdateAssignments >

Insert query class.

Template Parameters
IntoTableThe class representing the table or collection where the data is going to get inserted
InsertedColumnsSet of mem_ptr_wrappers containing the columns which would be given values. All columns should be from the same class.
InsertedValuesSet of set values and/or placeholders which would be replaced by arguments when the query gets executed
OnDuplicateKeyUpdateAssignmentsSet of assigments which would be executed on duplicated data being inserted
